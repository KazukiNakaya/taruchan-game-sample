# たるちゃんのおさんぽ — コンセプト & 実装方針

最終更新: 2026-10-18 / ステータス: 企画・設計(実装前)

---

## 1. ひとことで

犬のたるちゃんを操作して、森の小道をのんびりおさんぽする3Dゲーム。
落ちている「いいもの」をクンクン嗅ぎあてて集め、1回のおさんぽが「おさんぽ日記」の1ページになる。

- **ジャンル**: 3D探索・収集(ノンバトル、ゲームオーバーなし)
- **プレイ時間**: 1回のおさんぽ 3〜5分
- **雰囲気**: 癒し・ほっこり。急かさない、失敗させない
- **プラットフォーム**: Windows(PC)。操作はキーボード+マウス/ゲームパッド

## 2. 体験の核(ピラー)

1. **犬らしさが主役**: 首を振って周りを見る、匂いに反応して顔が向く、うれしいとしっぽを振る。操作しているだけで「犬っぽい」と感じられることを最優先にする。
2. **探すのが気持ちいい**: 答えを地図やマーカーで出さず、「たるちゃんの顔の向き」と「クンクン演出」で教える。
3. **短く、また行きたくなる**: 1回は短く、毎回少しずつ違うものが見つかる。集めたものが日記に残る。

## 3. コアループ

```
おさんぽ開始(森の入口)
  → 歩き回る / 周りを見る
  → 匂いに反応(顔が勝手に向く・しっぽが速くなる)
  → 近づいてクンクン(ボタン長押し)
  → 「いいもの」発見 → くわえて持ち帰る or その場でコレクション
  → ゴール(ベンチ/おうち)に着くとおさんぽ終了
  → おさんぽ日記に1ページ追加(見つけたもの・距離・時間)
```

## 4. 遊びの要素

### 4.1 移動
- 歩き(基本)と、ボタン押しっぱなしで小走り。
- スタミナ・落下死・ダメージは**なし**。

### 4.2 におい(探索のメイン)
- 「いいもの」はそれぞれ**におい半径**を持つ。
- 半径に入ると、たるちゃんの**首が自動でそちらを向く**(=ヒント)。近いほど首の追従が強く、しっぽが速くなる。
- 一定距離まで近づいて **クンクンボタン長押し(約1秒)** で発見。地面から掘り出す/草むらから出てくる演出。
- 画面上のUIヒントは最小限(オプションで「においマーカー」をONにできる程度)。

### 4.3 いいもの(収集物)
| 種類 | 例 | レア度 |
|---|---|---|
| ふつう | 木の枝、どんぐり、松ぼっくり、きれいな葉っぱ | ★ |
| ちょっといい | テニスボール、骨のおやつ、羽根 | ★★ |
| レア | 四つ葉、光るキノコ、昔のおもちゃ | ★★★ |

- 配置はスポーン地点リストからランダム抽選。毎回の中身が少し変わる。
- 全種類コンプリートが長期目標。

### 4.4 寄り道イベント(MVP後)
- 蝶々が飛んできて、追いかけると隠しアイテムの場所に案内される。
- ほかの動物(リス、カエル)に出会うと首をかしげるリアクション。
- 水たまりでブルブル、ベンチでおすわり休憩、など。

### 4.5 おさんぽ日記
- 1回のおさんぽ = 1ページ。日付、歩いた距離、見つけたもの、初発見マーク。
- 図鑑タブで収集済み/未発見(シルエット)を確認。
- セーブはローカル(`user://`)のみ。

## 6. アート・サウンド方針

- **キャラ**: Meshy AI製のたるちゃん(写真っぽいふわふわ質感)を主役に。
- **背景**: 森の小道。動画「たるちゃんのおさんぽ」で作った森(低めのローポリ寄り+柔らかい木漏れ日)を基準に、Godot側で組み直す。木や切り株はMeshyで数種類作って差し替え、作り物っぽさを減らす。
- **ライティング**: 午前中のやわらかい日差し、薄いフォグ。
- **サウンド**: 足音(土/草/葉っぱで変える)、鳥の声、クンクン音、発見時のやさしいジングル。BGMは控えめ。

## 8. 実装方針(Godot)

### 8.1 前提
- **エンジン**: Godot 4.7(`project.godot` の設定どおり)、Forward+、物理は Jolt Physics
- **言語**: GDScript(型ヒントあり)
- **単位**: 1 unit = 1 m。たるちゃんは体高 約0.4 m の実寸
- 実装は Claude Code で行う。このドキュメントは設計の基準として使う

### 8.2 フォルダ構成(案)

```
taruchan-game-sample/
├─ docs/                 企画・設計ドキュメント
├─ models/taruchan/      キャラ(glb)
├─ models/env/           背景モデル(木・岩・草など)
├─ scenes/
│   ├─ main.tscn         起動シーン(タイトル→おさんぽ→リザルト)
│   ├─ player/taruchan.tscn
│   ├─ camera/follow_camera.tscn
│   ├─ items/treasure.tscn
│   ├─ stages/forest_path.tscn
│   └─ ui/ (hud.tscn, result.tscn, diary.tscn)
├─ scripts/
│   ├─ player/  (taruchan.gd, sniff_sensor.gd, head_look.gd)
│   ├─ items/   (treasure.gd, treasure_spawner.gd)
│   ├─ systems/ (game_state.gd ※autoload, save_data.gd)
│   └─ ui/
├─ data/treasures/       いいもの定義(.tres)
└─ audio/
```

`blender_movie/`(動画関連)と `models/_blend/`(モデル・アニメのBlender作業ファイル)は `.gdignore` 入りの制作用フォルダなので、Godotからは見えない。

### 8.3 プレイヤー(たるちゃん)

**ノード構成**
```
Taruchan (CharacterBody3D)  ← taruchan.gd
├─ CollisionShape3D         カプセル(横倒し)または箱。体長 約0.45 m
├─ Model (taruchan_rigged.glb のインスタンス)
│   └─ Skeleton3D
│       └─ LookAtModifier3D  首(head ボーン)を注目対象に向ける
├─ AnimationTree            待機/歩き/小走り/クンクン/おすわり
├─ SniffSensor (Area3D)     におい検出 ← sniff_sensor.gd
└─ FootstepPlayer (AudioStreamPlayer3D)
```

**移動**
- カメラの向き基準で入力ベクトルを変換し、`velocity` を加減速付きで目標速度へ寄せる。
- 体の向きは移動方向へ `slerp` でゆっくり回す(犬は急に振り向かない)。
- 歩き 約0.32 m/s ×(ゲーム的に)1.5〜2倍程度、小走りはさらに約2倍。最終値は触って決める。
- アニメ速度は `移動速度 ÷ アニメ基準速度` を TimeScale に入れて足滑りを抑える(歩きの基準は 0.32 m/s)。

**モデルの向きに関する注意**
- glbのたるちゃんは glTF 前方(+Z)を向いている。Godotの前方は -Z なので、Model ノードを Y軸 180°回して配置するか、`look_at(..., true)`(use_model_front)を使う。

### 8.4 首の自動追従(このゲームの肝)

- `LookAtModifier3D` を head ボーンに設定し、`target_node` を「注目ターゲット」用の Marker3D にする。
- `head_look.gd` が毎フレーム注目先を決めて Marker3D を動かす。優先度:
  1. におい半径内で一番近い「いいもの」
  2. 蝶々・動物などのイベント対象
  3. 何もなければ「きょろきょろ」(数秒ごとにランダムな方向をゆっくり見る)
- ターゲットの切り替えはMarker3Dを補間移動させて、**向くときも戻るときもゆっくり**にする(動画制作で「戻るときにガクッとなる」問題が出たため)。
- **左右の可動域を非対称にする**: 元のモデルの顔が最初から横(犬自身の右側)を向いているため、首を左へ大きく振るとかなり不自然になることが動画制作で分かっている。左への最大角を小さめ(目安: 右45° / 左20°、要調整)にし、左側の対象は体ごと少し向きを変えて見る。
- 胸(chest)にも少し回転を分けると自然になる(動画では 首7:胸3 の配分)。

### 8.5 におい検出とクンクン

- `SniffSensor`(Area3D、半径 約3 m)に入った `Treasure` を候補リストに入れる。
- 一番近い候補を head_look に渡す。距離に応じてしっぽ振りの強さ、カメラの寄り、効果音を変える。
- 距離 0.6 m 以内でクンクン入力を長押し → 進行度ゲージ → 発見。発見時は掘り出しアニメ+ジングル+`GameState` に記録。

### 8.6 いいもの

- `TreasureData`(Resource): `id`, `display_name`, `rarity`, `mesh`/`scene`, `description`, `smell_radius`
- `Treasure`(Node3D or Area3D): `data: TreasureData`、発見状態、発見演出
- `TreasureSpawner`: ステージ内の Marker3D 群(`spawn_points` グループ)から、レア度の重み付きで抽選して配置

### 8.7 カメラ

```
FollowCamera (Node3D, top_level)  ← プレイヤー位置を遅れて追従
└─ SpringArm3D (長さ 約1.6 m、ピッチ -15°前後)
    └─ Camera3D (FOV 55〜60)
```
- 木や岩に当たったら SpringArm3D で縮む。
- クンクン中・発見時は少し寄る。
- 低めの視点(犬目線)を基本にする。

### 8.8 アニメーション

- `AnimationTree` の StateMachine: `Idle` / `Locomotion`(BlendSpace1D: 歩き↔小走り) / `Sniff` / `Sit` / `Dig`
- しっぽ振りは `Skeleton3D` の tail ボーンをスクリプトで揺らす(強さ・速さを状態で変える)か、Additive アニメにする。
- 首は LookAtModifier3D が上書きするので、アニメ側の首の動きは最小限でよい。

### 8.9 ゲーム全体

- `GameState`(autoload): 今回のおさんぽで見つけたもの、経過時間、距離、図鑑の解放状況
- セーブ: `user://save.tres`(図鑑・日記)。MVPでは不要
- シーン遷移: タイトル → `forest_path` → リザルト。ゴールは Area3D で判定

### 8.10 入力マップ(project.godot に追加)
`move_forward` / `move_back` / `move_left` / `move_right` / `run` / `sniff` / `sit` / `menu` / `camera_*`(パッド用)

## 12. ここまでの経緯と分かっていること(Blender作業の記録)

実装やアニメ追加のときに知っておくべき事実をまとめる。

### 12.1 モデルの加工内容(Meshy → `taruchan_rigged.glb`)
- Meshy の元GLBは実寸が約2 mm、スケール0.01・X軸90°回転付きだった。**高さ0.4 m に拡大**し、回転・スケールを適用して1にした。
- ボーンの先端(tail)の位置が大きくずれていたので、向きは変えずに長さだけ子ボーンまでに直した(アニメへの影響なし)。
- 足の最下点が z=0 になるよう持ち上げた(接地済み)。
- ボーン表示用の補助オブジェクト(Icosphere)は削除した。
- **ボーン構成(27本)**: `Hips` /しっぽ `tail` `tailstart` `tail1` `tail2` `tail3` /後ろ足 `backleg` `backleg0-2`、`R_backleg` `R_backleg0-2` /`chest` /`head` `headend` `earend` `R_earend` /前足 `frontleg` `frontleg0-2`、`R_frontleg` `R_frontleg0-2`
- ボーンのローカル軸の向きはバラバラ(自動リグのため)。**首をスクリプトで「X軸で回す」のような書き方は避け、LookAtModifier3D のような目標位置ベースで動かす。**

### 12.2 向きと速度
- 犬の前方は Blender では -Y、glTF/Godot では **+Z**。Godotの前方(-Z)とは逆。
- 歩きは24フレーム(24fps で1秒)で1サイクル。足が滑らない速度は **約0.32 m/s**(1フレームあたり 0.0132 m)。

### 12.3 首の向きについての重要な知見
- **元モデルの顔は最初から犬自身の右側へねじれている**(首のボーンが正面でも、顔は横を向いて見える)。
- 動画制作で、首の基準を左へ50°ずらすと顔は正面になったが、**首を左に向けるととても不自然になった**ため取りやめた。モデルはこのまま使う。
- そのためゲームでは、**首の左右の可動域を非対称にする**(左は小さく)。左側を見せたいときは体ごと向きを変える(8.4参照)。
- 首は「向くときも戻るときもゆっくり」が必須。急に戻ると一瞬で違和感が出る。動画では臨界減衰のばね(バネ定数 0.01〜0.02/フレーム)でなめらかにした。
- 首の回転は **head 7 : chest 3** に分けると自然。下を嗅ぐときは胸も最大3割ほど下げ、前足(`frontleg` `R_frontleg`)を逆回転させて地面から浮かないようにした。

### 12.5 Blender 5.2 で引っかかった点
- F-Curve の Cycles モディファイアでのループが、この作業では効かなかった。ループさせたいアニメは**全フレームを焼き込む**。
- Blender 5.x のアクションはレイヤー構造(`action.layers[].strips[].channelbags[].fcurves`)になっている。スクリプトで F-Curve を触るときは注意。
